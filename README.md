# TECH CAREER MULTIVERSE — Trắc Nghiệm Khám Phá Nghề Nghiệp CNTT, Game & AI

Mini game trắc nghiệm 7 câu hỏi tương tác thời gian thực dành cho lớp học, workshop, ngày hội tuyển sinh và sự kiện hướng nghiệp công nghệ thông tin. Sinh viên quét mã QR tham gia trên điện thoại di động, lựa chọn chuyên ngành quan tâm và kết quả hiển thị trực tiếp lên màn hình Admin / Máy chiếu.

---

## 🌟 Chuyên Ngành Mở Rộng (Tracks)

1. 🎮 **Lập Trình & Thiết Kế Game (Game Development)**:
   - 🕹️ **Gameplay Programmer**: Logic game, combat combo, cơ chế di chuyển, AI bot.
   - 🎨 **Game Artist & VFX**: Đồ họa 3D, Blender, Shader Graph, ánh sáng và hiệu ứng phép thuật.
   - 📜 **Game Designer**: Kịch bản, level design, cân bằng kinh tế và luật chơi.
   - ⚙️ **Game Engine Architect**: C++, Vulkan/DirectX, tối ưu hóa bộ nhớ và hiệu năng 120 FPS.
   - 🎯 **Game Tester & QA**: Bắt glitch kẹt map, cân bằng sức mạnh và kiểm thử trải nghiệm.

2. 🤖 **Lập Trình AI & Khoa Học Dữ Liệu (AI & Data Science)**:
   - 🧠 **GenAI & AI Agent Architect**: LLM, Prompt Engineering, LangChain, RAG, Multi-Agent.
   - 🔬 **Deep Learning & ML Scientist**: PyTorch, Transformers, GPU CUDA, huấn luyện model.
   - 📊 **Data Scientist & Big Data**: SQL, BigQuery, phân tích dữ liệu lớn và trực quan hóa.
   - 👁️ **Computer Vision & Robotics**: OpenCV, YOLO, Segment Anything, thị giác máy tính & xe tự hành.
   - ⚡ **MLOps & AI Infrastructure**: Docker, Kubernetes, Triton Inference, triển khai model 24/7.

3. 🌐 **Lập Trình Web & Hệ Thống Đám Mây (Web & Cloud Development)**:
   - 🎨 **Frontend Master**: React, Next.js, CSS Motion, tối ưu tốc độ 60fps.
   - ⚙️ **Backend & Microservices**: Node.js, Golang, PostgreSQL, Redis, Kafka.
   - ☁️ **DevOps & Cloud Architect**: Docker, Kubernetes, CI/CD, AWS/GCP, hạ tầng bất biến.
   - ⚡ **Fullstack Ninja**: Toàn năng từ ý tưởng đến triển khai sản phẩm hoàn chỉnh.
   - 👁️ **Web UX Specialist**: Trải nghiệm người dùng, Design System, tối ưu chuyển đổi.

4. 🔮 **Đa Vũ Trụ CNTT (IT Multiverse — Tổng Hợp)**:
   - Khám phá toàn diện hướng đi phù hợp giữa AI, Game, Web, An toàn thông tin (Cyber Security), Quản lý sản phẩm (Product Owner) và UI/UX Design.

---

## 🚀 Công Nghệ
- **Frontend**: HTML5, CSS3 (Modern Cyberpunk & Glassmorphism Theme, Responsive Mobile-First), Vanilla JavaScript.
- **Backend Server**: Node.js HTTP Server (`server.js`) tích hợp RESTful API & Static file server (không cần cài thêm dependency phụ).
- **Tương tác thời gian thực**: Auto Polling Dashboard mỗi 3 giây với bộ lọc theo chuyên ngành.
- **Mã QR tích hợp**: Tự động sinh mã QR độ nét cao chiếu lên máy chiếu cho hội trường/lớp học.

---

## ⚡ Cách Chạy Nhanh

### Cách 1: Chạy trực tiếp bằng Node.js (Khuyên dùng)
```bash
node server.js
```
Truy cập:
- 🎮 **Màn hình người chơi:** `http://localhost:3000/`
- 📊 **Màn hình Admin / Máy chiếu:** `http://localhost:3000/admin.html`

### Cách 2: 1-Click trên Windows
Click đúp vào file `start.bat`.

## 🔄 Luồng Trải Nghiệm
1. **Người chơi:** Truy cập trang chủ ➔ Nhập tên & Chọn chuyên ngành (Game, AI, Web, Đa vũ trụ) ➔ Trả lời 7 câu hỏi tình huống hấp dẫn ➔ Nhận kết quả phân tích cá tính nghề nghiệp, danh sách kỹ năng trọng tâm và lời khuyên lộ trình.
2. **Admin / Giảng viên:** `admin.html` hỗ trợ lọc kết quả theo từng chuyên ngành, xem bảng phân bố vũ trụ và danh sách sinh viên tham gia trực tiếp theo thời gian thực.
